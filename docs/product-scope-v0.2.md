# Raychi v0.2 · lantern 公开站任务说明

状态：待实现；[模块 Issue #2](https://github.com/raychi-space/lantern/issues/2)，[跨仓主 Issue #1](https://github.com/raychi-space/raychi/issues/1)。项目级产品依据见 [Raychi 产品需求 v0.2](https://github.com/raychi-space/raychi/blob/main/docs/product-v0.2.md)；当前公开站仍仅实现首页和长文列表/详情。本文只列公开站职责，不定义 HTTP 字段或后端状态规则。

## 访客路径

1. 首页顶部显示头像、站名与一句简短介绍；主体把已发布的长文、帖子、思考按公开发布时间混排。每项标明内容类型。长文用标题、摘要和封面卡片；帖子直接显示文字；思考正文较长时可展开或进入详情。
2. 长文、帖子、思考各有列表和详情。帖子与思考标题可空；空标题时列表和详情直接以正文为主要文字，仍有稳定可分享的详情链接。帖子与思考不显示图片入口或空封面。长文无封面时呈现根据标题生成的默认封面。
3. 「回顾」按年、月显示三类已发布内容，每项仅列日期、类型、标题（如有）及正文首句，支持筛选并链接详情。「更多」保留入口，项目等内容暂缓。
4. 全站显示管理端保存后立即生效的站名、简短介绍、头像、联系方式、外部账户、导航文字/链接及首页区块显示与顺序。联系方式和外部账户在页脚可用。
5. 仅展示发布快照。暂存工作稿不改变访客看到的内容和公开顺序；再次发布后才更新；撤回后从首页、栏目、回顾和详情中不可见。现有长文链接继续有效。

## 接口依赖与交付

- 等待 wellspring 先确认混合公开列表、三类详情、回顾筛选、分类/标签与站点配置的 OpenAPI。前端不能自行推断草稿、默认分类或撤回的响应。
- 页面名称和新路径、长文默认封面生成方式、思考折叠阈值、回顾筛选控件及移动端布局在视觉设计中定稿。保持直接访问详情页的能力。
- 保持 Markdown 安全渲染与图片公开权限边界；帖子、思考的正文不渲染图片。现有文章图片代理行为不能退化。

## 模块验收

- 三种已发布内容按实际发布时间混排；缺标题的帖子/思考在首页、列表和详情可读且可分享；长文封面缺省时有可用的默认呈现。
- 回顾的年/月分组、摘要行和筛选结果正确；撤回及仅保存工作稿不泄露新正文，旧长文地址仍可读。
- 修改站点配置并刷新公开站后看到新值；手机端可读；首页区块显示与顺序按配置呈现。
- 运行 `npm run typecheck && npm run build`，再用当前 wellspring 验证真实页面和匿名权限；构建通过不能代替跨仓验收。
